# 🏔️ 桂林陽朔 5 日親子行程 · 山水紀行

> 一家四口（2 大 + 8 歲姐姐 + 6 歲妹妹）的桂林陽朔龍脊 5 日 4 夜旅行計畫。

## ⛔ 暴雨應變（7/6 晚更新）

- **灕江四星遊船 7/7 停航確定** → 7/7 早上原平台辦全額退款 ¥1,140，改包車走高速直達陽朔（65km · 約 1.5h）
- **遇龍河可能封漂** → 每晚 20:00 看「遇龍河」公眾號公告再搶票：7/7 晚搶 7/8；沒漂成 7/8 晚再搶 7/9 早場補位（飛拉達讓位）
- **龍門水岩是水洞** → 暴雨後可能漲水關閉，出發前必電話確認；備選銀子岩（旱洞不受雨影響）
- **灕江山水補回來** → 若 Day 4 封漂，改興坪古鎮 + 20 元人民幣背景步行打卡（封航不影響古鎮）
